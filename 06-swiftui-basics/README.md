# 06. SwiftUI Basics

## Concepts
- View protocol
- Stacks & layout
- Modifiers
- Previews

## What you’ll build
A single-screen SwiftUI profile card.

## Project type
Xcode iOS app (SwiftUI) + project.yml

## Steps overview
1. Open the .xcodeproj in Xcode
2. Run on Simulator
3. Implement the TODO layout

## Stretch goals
- Add a dark/light-friendly hierarchical ShapeStyle
- Extract a ProfileHeader subview

## Required tooling
**Xcode 27** recommended (iOS 27 SDK). Minimum conceptually iOS 17+ / Xcode 16+.

## Docs (verify APIs here)
- [SwiftUI](https://developer.apple.com/documentation/swiftui)
- [SwiftUI Tutorials](https://developer.apple.com/tutorials/swiftui)

## Untested / Apple-only notes
- Cannot compile SwiftUI iOS apps on Linux — open in Xcode on a Mac.
- Committed .xcodeproj was generated without Xcode; if it misbehaves, regenerate with `xcodegen` from project.yml.
